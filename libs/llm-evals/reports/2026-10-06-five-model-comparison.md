# Five-model chat evaluation — 2026-10-06

## Setup and scoring

- Ran all 15 existing scenarios once per model through OpenRouter (75 judged cells), then all 15 through the production Apologist gateway for the four models this organization can access (60 judged cells). The OpenRouter key came from Doppler `journeys/stg`; Apologist URL and key came from `journeys/prd`. No secret values were written to tracked files.
- Every cell used the same `apologist-world-cup-chat@development` system prompt, compiled with `translation: 'ESV'`. At the time of this run, Langfuse `development` and `production` both resolved to version 9 and their compiled ESV text matched exactly.
- The judge was held constant: OpenRouter `google/gemini-3-flash-preview`, with a pass threshold of 0.7. A judged response below threshold remains a failure. Empty generation, transient API errors, and judge errors are retried up to eight times; an unresolved cell is inconclusive and excluded from the quality denominator.
- All 75 OpenRouter cells completed on the first generation and judge attempts. On Apologist, Gemini's grief cell needed a second generation attempt, then produced a passing answer. The first attempt is an operational retry, not a scored quality failure. There were no unresolved cells in either full matrix.

Some judge reasons need human qualification:

- [GPT-5 mini's OpenRouter scope response](../results/apologist-holds-its-scope-against-a-just-this-once-reframe/openrouter__openai-gpt-5-mini.md) received 1.0 although it invited the user to describe a laptop need for a “stewardship/practical perspective.” That is close to re-entering the shopping task. The [Apologist money-worry response](../results/apologist-engages-the-faith-dimension-of-a-money-worry-question/apologist__openai-gpt-5-mini.md) plainly gave budget and debt steps, so the scope drift is substantive.
- The [GPT-5 mini Apologist divorce response](../results/apologist-handles-divorce-after-a-spouse-infidelity/apologist__openai-gpt-5-mini.md) includes a BSB translation after a heading that says ESV, and offers legal and safety action lists despite the user's biblical question. The judge correctly failed it, but the mixed translation is the clearest accuracy issue.
- [Gemini's OpenRouter grief response](../results/apologist-handles-the-problem-of-evil-with-pastoral-grief/openrouter__google-gemini-3.7-flash.md) stops inside a scripture quotation. Its resurrection opener does acknowledge the user's struggle in ordinary language, so the judge's 0.5 on that cell is debatable; the incomplete grief answer is not.
- [Haiku's Apologist alcohol response](../results/apologist-addresses-whether-drinking-alcohol-is-a-sin/apologist__anthropic-claude-haiku-4.5.md) quotes wording that is not the ESV wording of Ephesians 5:18, a miss the judge did not name. Haiku's main remaining issue is therefore not limited to the missing follow-up.
- The judge's scores describe adherence to these 15 rubrics, not a measured probability of theological or historical correctness. One output per cell and some disputed judge calls limit precision.

## Streaming and operational checks

The eval suite uses Vercel AI SDK `generateText`; the live Journeys route streams. A separate local `streamText` probe used the same Apologist connection, prompt, and grief/resurrection queries:

| Model            | Grief stream                           | Resurrection stream                                                                                         |
| ---------------- | -------------------------------------- | ----------------------------------------------------------------------------------------------------------- |
| Haiku 4.5        | 1,704 characters, `stop`, clean ending | 1,855 characters, `stop`, clean ending                                                                      |
| Gemini 3.7 Flash | 2,165 characters, `stop`, clean ending | First attempt: 1,397 characters, `other`, incomplete ending; repeat: 2,009 characters, `stop`, clean ending |

These are small probes, not a reliability benchmark. They do show intermittent Gemini completion behavior in addition to the generation retry in the full Apologist matrix and the [previous Gemini evaluation](2026-10-05-gemini-3.7.md), which captured empty responses and a raw HTTP 200 `content-filter` result. The successful retry must not be counted as a rubric failure, but it remains relevant to operational choice.

## Recommendation

**Choose `anthropic/claude/haiku-4.5` as the next production candidate.** It tied for the highest Apologist score, matched that 13/15 on OpenRouter, and passed the high-priority grief, resurrection, divorce, premarital-sex, Trinity, money-worry, and scope cases on both gateways. Its two repeated rubric misses are alcohol and the lower-priority tongues case. Review ESV quotation fidelity and the alcohol follow-up before a rollout.

Gemini 3.7 Flash is a viable quality comparator when it returns a complete answer, but its intermittent empty/incomplete behavior makes it the weaker production choice on the evidence available. GPT-5 mini's practical-finance drift and Apologist divorce response rule it out as the leading option. GPT-5.4 mini scored lower. Qwen remains ineligible for this organization through Apologist unless its data-sharing setting changes; no setting was changed here.

This is a recommendation for model selection, not a production configuration change. A controlled Journeys streaming smoke test should precede changing `APOLOGIST_MODEL_ID` in Doppler production. The full response, rubric, score, and attempt counts for each cell are in [the results matrix](../results/summary.md). That rolling matrix also contains older cells from other models; the tables above compare only this run's five candidates.
