This throwaway review asks whether the agreed workflow is understandable when edits conflict, a response is lost, an upload moves to Admin, or access changes. It starts with an existing journey. Each saved batch is one undo step; media attachment is a separate save.

Everything is synthetic and in memory. This is neither the MCP service nor a security test. The reviewer can see full model state even when the simulated agent is denied. It illustrates selected cases, not the complete editor operation inventory. No network calls, files, accounts or journey data are used. The demo does not simulate provider uncertainty, distributed locking, exact retention cleanup or the full upload quota.
